# Trusted Firebase development tools

Run `npm install` here after installing Node.js 22+; Java 21 is needed for the Firestore emulator. The package lockfile is generated by your installation, not pre-generated in the archive.

- `npm run validate` validates seed JSON and bundled assets.
- `npm run test:data` runs the dependency-free seed-data tests.
- `npm run emulators` runs local Auth and Firestore emulators for `demo-recipe-app`.
- `npm run seed:demo` seeds a running local emulator.
- `npm run test:rules` starts a separate Firestore emulator and runs the rule suite.

Do not run `test:rules` simultaneously with a development Firestore emulator on the same port. See `../docs/FIREBASE_SETUP.md` for cloud seeding, explicit project confirmation and credentials. Admin credentials belong outside this repository and never inside the Flutter application.

No production project was provisioned, seeded or deployed when this source was created.
